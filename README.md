O Valida_CNSP é o programa desenvolvido em um único arquivo de código para validar informações de carga, usinas não simuladas e patamares geradas no deck do COBRE pelo conversor.

A pasta Validador_Hidraulicas_4_abas contém a versão atual do validador das grandezas associadas às usinas hidrelétricas.

Para executar o validador hidráulico, deve-se iniciar a rotina:

compare_hidros.py
